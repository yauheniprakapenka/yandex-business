# Подключение подменных номеров для сетей

> Source: https://yandex.ru/support/business-priority/ru/branches/spoofed-num

В этой статье:

- [Как подключить](#как-подключить)
- [Как управлять](#как-управлять)

> Подменный номер — бесплатная услуга подмены телефонного номера для отслеживания звонков по рекламной подписке.

## Как подключить

В зависимости от вашей рекламной кампании, вы можете подключить *подменный номер* на вкладке **Рекламные материалы** или **Настройки**.

### Рекламные материалы

1. Выберите нужную рекламную кампанию.
2. Перейдите на вкладку **Рекламные материалы** и пролистайте страницу до блока **Подменный номер**.
3. Нажмите **Добавить**.
4. Укажите телефонный номер, на который будет перенаправляться звонок, добавьте описание и нажмите **Сохранить**.

    Подменный номер будет работать для филиалов этой компании.

    Чтобы изменить количество филиалов с этим подменным номером в блоке **Подменный номер**, нажмите **Подменный номер** → **Изменить**. Уберите галочку напротив филиалов, у которых хотите отключить подменный номер.

### Настройки

1. Выберите нужную рекламную кампанию.
2. Перейдите на вкладку **Настройки**.
3. В блоке **Подменный номер** нажмите **Подключить**.
4. Выберите телефонный номер, который нужно подменить и укажите его в поле **Телефон для клиентов**.
5. В поле **Филиалы** нажмите значок редактирования. В новом окне выберите нужные филиалы сети.

    Чтобы отменить выбор, уберите галочку напротив филиалов, у которых хотите отключить подменный номер.

6. Укажите **Описание телефона**. Оно будет отображаться рядом с телефоном в профиле филиала в Картах.
7. Нажмите **Подключить**.

    В блоке **Подменный номер** появится пометка **Активно**. Для каждой рекламной кампании будет указан **Телефон, который видит клиент** и **Куда поступают звонки**.

Подменный номер начнет работать после оплаты и запуска рекламной кампании.

## Как управлять

Как отслеживать звонки, изменить или отключить подменный номер, читайте на странице [Подмена номера](https://yandex.ru/support/business-priority/ru/spoofed-phone-number#how-to-track).
