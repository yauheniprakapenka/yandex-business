# Сетевые организации

> Source: https://yandex.ru/support/business-priority/ru/branches/several-branches

*Сеть* — это объединение нескольких компаний в одну группу. В сети вы можете:

- [обновлять информацию](https://yandex.ru/support/business-priority/ru/branches/basic) одновременно у нескольких филиалов;
- [загрузить один логотип](https://yandex.ru/support/business-priority/ru/branches/logo) для всей сети;
- [добавить прайс-лист](https://yandex.ru/support/business-priority/ru/branches/price) для всех филиалов в регионе.

Переход по активной ссылке **Все филиалы сети** в профиле одного из филиалов в Яндекс Картах позволяет увидеть все филиалы сети.

Для владельцев сети упрощена процедура верификации профилей компаний:

- Вы подтверждаете свои права на сеть и получаете доступ ко всем профилям филиалов.
- Новые филиалы после прохождения модерации автоматически отображаются в Личном кабинете. Подтверждать их еще раз не придется.
