# Как обновлять данные о филиалах

> Source: https://yandex.ru/support/business-priority/ru/branches/basic

Добавлять филиалы и обновлять данные о них можно несколькими способами:

**Вручную в интерфейсе Яндекс Бизнеса**

Этот способ подходит для сетей с небольшим количеством филиалов (меньше 30), в которых информация о филиалах меняется редко.

Подробнее см. в разделе [Как обновлять данные сети вручную](https://yandex.ru/support/business-priority/ru/branches/branches-manual).

**Через файл формата XML (рекомендуется) или CSV**

Этот способ подходит для сетей, в которых больше 30 филиалов.

Преимущества обновления через файл формата XML:

- Данные о ваших филиалах будут всегда актуальны во всех сервисах и мобильных приложениях Яндекса. Ваши потенциальные клиенты смогут легко добраться до ближайшего филиала с помощью [Яндекс Карт](https://yandex.ru/maps/), [Яндекс Навигатора](https://yandex.ru/support/navigator/ru/), найти филиал в [Поиске](https://ya.ru/) и других сервисах Яндекса.
- Вы можете полностью автоматизировать передачу данных о филиалах, если настроите выгрузку данных из своей базы 1С, ERP (SAP, Axapta) или других систем.
- Через XML‑файл вы можете передавать полную информацию о филиалах, в том числе фотографии и дополнительные параметры.

Подробнее см. в разделах [Обновление данных через XML‑файл](https://yandex.ru/support/business-priority/ru/branches/branches-xml) и [Обновление данных через CSV‑файл](https://yandex.ru/support/business-priority/ru/branches/branches-csv).

**Разместить данные на своем сайте и написать в службу поддержки**

Вы можете разместить данные о филиалах на своем сайте, чтобы их автоматически собирал робот Яндекс Бизнеса. Это наименее эффективный способ, потому что при получении данных могут возникнуть сложности. Используйте его, только если другие варианты вам не подходят.
