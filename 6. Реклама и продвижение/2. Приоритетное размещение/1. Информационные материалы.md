# Рекламно-информационные материалы

> Source: https://yandex.ru/support/business-priority/ru/benefits-materials

Вы можете создавать и редактировать дополнительные рекламно-информационные материалы для продвижения вашей компании. Пользователи увидят их здесь:

- веб‑версия [Яндекс Карт](https://yandex.ru/maps/) для компьютеров и мобильных устройств;
- мобильное приложение [Яндекс Карты](https://ya.ru/all?mode=apps&service=maps) для Android и iOS;
- мобильное приложение [Яндекс Навигатор](https://ya.ru/all?mode=apps&service=navi) для Android и iOS.

Для этого перейдите в раздел **Продвижение**, выберите кампанию, откройте вкладку **Материалы** и воспользуйтесь инструкцией для [управления и настройки](https://yandex.ru/support/business-priority/ru/promotion/benefits-materials-old).
