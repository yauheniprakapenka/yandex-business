# Рекламно-информационные материалы

> Source: https://yandex.ru/support/business-priority/ru/adv-materials

Вы можете создавать и редактировать дополнительные рекламно-информационные материалы для продвижения вашей компании. Пользователи увидят их здесь:

- [Яндекс Поиск](https://ya.ru/) для компьютеров и мобильных устройств;
- веб‑версия [Яндекс Карт](https://yandex.ru/maps/) для компьютеров и мобильных устройств;
- мобильное приложение [Яндекс Карты](https://ya.ru/all?mode=apps&service=maps) для Android и iOS;
- мобильное приложение [Яндекс Навигатор](https://yandex.ru/all?mode=apps&service=navi) для Android и iOS;
- сайты партнеров Яндекса.

Инструкции по настройке отличаются для разных интерфейсов. Проверьте, как выглядит ваш. Для этого перейдите в раздел **Продвижение**, выберите кампанию и откройте вкладку **Материалы**.

- [Новый интерфейс](https://yandex.ru/support/business-priority/ru/promotion/adv-materials-new)
- [Старый интерфейс](https://yandex.ru/support/business-priority/ru/promotion/adv-materials-old)
