# Интеграция с Ozon Performance API

> Source: https://yandex.ru/support/business-priority/ru/ozon-api

В этой статье:

- [Как настроить интеграцию](#как-настроить-интеграцию)
- [Как обновить АPI‑ключи](#как-обновить-apiключи)

> Ограничение
>
> Интеграция доступна только с кабинетом продавца (Ozon Seller).

Вы можете настроить обмен данными между вашим магазином на Ozon и Яндекс Бизнесом с помощью интеграции Ozon Performance API. Интеграция позволит:

- Яндекс Бизнесу лучше подбирать клиентов, которым понравятся ваши товары;
- получать в личном кабинете Ozon Seller больше статистики: сколько человек пришли по рекламе и совершили покупки или положили товары в корзину.

## Как настроить интеграцию

1. Перейдите в раздел **Продвижение**. Если вам доступна возможность интеграции, вы увидите баннер о преимуществах подключения API.
2. На баннере **Ваша реклама станет эффективнее** нажмите **Настроить**.
3. Получите и заполните *API‑ключи* для интеграции по предложенным шагам.

   Подробнее о том, как получить АPI‑ключи в личном кабинете на Ozon:

   1. В разделе **Аналитика** выберите **Внешний трафик**. Скопируйте и сохраните значение поля **Префикс для метки UTM\_CAMPAIGN** вида `vendor_org_*****`.
   2. В этом же разделе нажмите **Создать ссылки**. В открывшемся блоке **Сервисные аккаунты** нажмите **Создать аккаунт**.
   3. Нажмите **Добавить ключ**. Скопируйте значения столбцов **Client ID** и **Client Secret**.

4. Нажмите **Сохранить**. Если все заполнено верно, вы увидите сообщение «Ozon Performance API настроен».

Яндекс Бизнес создаст рекламные объявления с вашими товарами и будет передавать статистику по переходам в личный кабинет Ozon Seller.

**Где посмотреть статистику**

1. В личном кабинете Ozon Seller в разделе **Аналитика** выберите **Внешний трафик**.
2. Нажмите **Сгенерировать отчет**.

## Как обновить АPI‑ключи

1. Перейдите в раздел **Продвижение** на вкладку **Настройки**.
2. В блоке **Обмен Данными** напротив Ozon Performance API нажмите **Настроить**.
3. Внесите изменения и нажмите **Сохранить**.
