## Формат файлов

Каждый markdown-файл оформлен по шаблону:

```markdown
# <Title страницы>

> Source: <URL>

<текст страницы>
```

- Папки и файлы именуются по схеме `NN. Название раздела/` /
  `NN. Название страницы.md`, где `NN` — порядковый номер (две цифры).
- Внутри каждой папки нумерация сквозная.
- Внутренние относительные ссылки (`ru/...`) преобразуются в абсолютные
  (`https://yandex.ru/support/business-priority/ru/...`).
- Внешние ссылки остаются как есть.

Подробное дерево папок и файлов описано в [AGENTS.md](AGENTS.md).
