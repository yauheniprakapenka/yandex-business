Прайс-листы могут загружать компании через Личный кабинет в Яндекс Бизнесе (см. [Прайс-лист компании](https://yandex.ru/support/business-priority/ru/manage/price-list)), а также партнеры Яндекс Бизнеса.

*Партнер* — это сервис, который сотрудничает с Яндексом и передает информацию об организациях, их товарах и услугах.

После загрузки прайс-листа партнером Яндекс Бизнес добавляет данные из фида в личные кабинеты компаний. Редактировать товары из источника партнера через личный кабинет нельзя.

Владелец организации может выбрать или изменить источник прайс-листа, загрузить собственный прайс-лист или скрыть товары из источника. Чтобы изменить источник:

1. В Личном кабинете перейдите на вкладку **Товары и услуги**.
2. Нажмите ссылку рядом с полем **Источник**.
3. Выберите нужный вариант.

Подробнее см. в разделе [Как загрузить прайс-лист из другого источника](https://yandex.ru/support/business-priority/ru/manage/price-list#partners).

**Требования к партнеру**

- У партнера есть информация об актуальных товарах и услугах компаний, которые представлены на Яндекс Картах.
- Количество компаний, для которых предоставляется информация — не меньше 1000.
- Данные о товарах и услугах получены легально и соответствуют [требованиям к прайс-листам](https://yandex.ru/support/business-priority/ru/manage/price-list#rules).
- Данные получены от компаний, которые работают офлайн и у которых есть фактический адрес (см. [Адрес и местоположение](https://yandex.ru/support/business-priority/ru/manage/address)).

## Как подключить

### Создайте фид

Создайте *фид* — файл, который содержит список всех товаров и/или услуг.

**Требования к файлу:**

- Формат — построчный JSON. Каждая строка содержит один товар или услугу, представленный в виде объекта JSON.
- Кодировка данных — UTF-8.
- Обязательные поля отмечены звездочкой.

**Поля фида:**

| Поле | Описание |
| --- | --- |
| `yandex_company_id`\* | ID организации в Яндекс Картах. Например, `1124715036`. Вы можете получить его из прямой ссылки на компанию, например `https://yandex.ru/maps/org/yandex/1124715036`. |
| `yandex_company_ids`\* | Значение `yandex_company_id` в виде списка, если один товар или услуга относятся к множеству компаний. В каждой строке разрешается указывать только одно из полей `yandex_company_id` или `yandex_company_ids`. |
| `source_id`\* | Уникальный артикул товара, SKU. До 80 символов. Может содержать цифры, латинские и русские буквы (кроме «ё»), символы `. , \ / ( ) [ ] - =`. |
| `name`\* | Наименование товара или услуги. До 250 символов. |
| `description` | Описание товара. До 250 символов. |
| `price`\* | Точная стоимость товара или услуги. Диапазон цен указывать не разрешается. До 20 символов. Может содержать только цифры, `.`, `,`. Товар или услуга с ценой «0» или без цены не будут опубликованы. |
| `currency_id` | Код валюты в формате ISO 4217. Если не указан, то будет использовано значение по умолчанию для страны, в которой работает компания: BYN — для Беларуси, KZT — для Казахстана и RUB — для России и остальных стран. |
| `is_popular` | Укажите `true`, чтобы выбранный товар или услуга отображались в галерее популярных товаров в профиле компании на вкладке **Обзор**. Всего в прайс-листе можно отметить не больше 10 популярных товаров или услуг. |
| `category` | Раздел прайс-листа, к которому относится товар или услуга. До 250 символов. В профиле компании прайс-лист публикуется с разделением по указанным категориям. |
| `photo_link` | Одна прямая ссылка на файл с изображением. Ссылка на Яндекс Диск не подойдет, так как ведет на HTML-страницу, а не на изображение. Ссылка может быть: без явного указания ТСР-порта; с портом из набора: 80, 443 или 8080. Поддерживается выгрузка только по протоколам HTTP и HTTPS. Выгрузка по FTP, SMB и другим протоколам не поддерживается. |
| `market_url` | Прямая ссылка на страницу товара на сайте. Переход по ссылке доступен только в десктопной версии для компаний с [Рекламной подпиской](https://yandex.ru/support/business-priority/ru/promotion/order). |

**Схема строки файла (JSON Schema):**

```json
{
    "$schema": "http://json-schema.org/draft-07/schema#",
    "definitions": {
        "price_item": {
            "description": "Товар для размещения",
            "type": "object",
            "properties": {
                "yandex_company_id": {
                    "description": "ID организации на Яндекс Картах",
                    "type": "integer"
                },
                "yandex_company_ids": {
                    "description": "Множественные ID организаций на Яндекс Картах",
                    "type": "array",
                    "items": {
                        "type": "integer"
                    },
                    "uniqueItems": true
                },
                "source_id": {
                    "description": "ID товара в вашей системе",
                    "type": "string",
                    "maxLength": 80
                },
                "name": {
                    "description": "Наименование товара",
                    "type": "string",
                    "maxLength": 250
                },
                "is_popular": {
                    "description": "Популярные товары формируют витрину (не более 10 штук)",
                    "type": "boolean"
                },
                "price": {
                    "description": "Цена товара",
                    "type": "number"
                },
                "description": {
                    "description": "Описание товара",
                    "type": "string",
                    "maxLength": 250
                },
                "category": {
                    "description": "Категория товара",
                    "type": "string",
                    "maxLength": 250
                },
                "photo_link": {
                    "description": "Ссылка на фотографию",
                    "type": "string"
                },
                "currency_id": {
                    "description": "Код валюты ISO 4217",
                    "type": "string",
                    "maxLength": 10
                },
                "market_url": {
                    "description": "Ссылка на товар",
                    "type": "string"
                }
            },
            "required": [
                "source_id",
                "name",
                "price",
                "currency_id"
            ],
            "oneOf": [
                {
                    "required": [
                        "yandex_company_id"
                    ]
                },
                {
                    "required": [
                        "yandex_company_ids"
                    ]
                }
            ]
        }
    },
    "$ref": "#/definitions/price_item"
}
```

Скачайте [пример файла](https://doc-static.yandex.net/src/support/business-priority/ru/example_feed.json).

Чтобы защитить файл, вы можете установить *секрет* — строчку, которую мы будем передавать в `header` или параметре запроса.

### Подключите фид к Яндекс Бизнесу

1. Cформируйте постоянную ссылку на файл.

    > Внимание
    >
    > Обновления данных должны происходить без изменения ссылки.

2. Перейдите в форму [Товары и услуги компании](https://forms.yandex.ru/surveys/13485724.a1310d38f50da2df17deb93bfdb4b514c5679847/?lang=ru).
3. В списке **С чем вы столкнулись?** выберите **Подключить товарный фид партнера**.

Период загрузки и обновления файла — один раз в сутки.

## Как это работает

После интеграции информация об источнике данных появится:

- В Личном кабинете Яндекс Бизнеса в разделе **Товары и услуги** в меню **Источник товаров и услуг**. Подробнее см. [Как загрузить прайс-лист из другого источника](https://yandex.ru/support/business-priority/ru/manage/price-list#partners).
- В профиле компании в Яндекс Картах на вкладке **Товары и услуги** или **Меню**.
