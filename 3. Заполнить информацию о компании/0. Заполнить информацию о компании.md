# Заполнить информацию о компании

> Source: https://yandex.ru/support/business-priority/ru/manage/edit

Возможности Личного кабинета зависят от вида вашей компании.

| Возможность | Компания с фактическим адресом | Онлайн-компания |
| --- | :---: | :---: |
| Добавить и отредактировать [данные компании](https://yandex.ru/support/business-priority/ru/manage/data) | Да | Да |
| Загрузить [логотип и фотографии](https://yandex.ru/support/business-priority/ru/manage/photos) | Да | Да |
| Добавить [прайс-лист](https://yandex.ru/support/business-priority/ru/manage/price-list) | Да | Да |
| Рассказать о [способах доставки](https://yandex.ru/support/business-priority/ru/manage/delivery) | Да | Да |
| Скачать [промоматериалы](https://yandex.ru/support/business-priority/ru/manage/promo) | Да | Да |
| Разместить [публикации](https://yandex.ru/support/business-priority/ru/manage/publications) | Да | Да |
| Разместить [события](https://yandex.ru/support/business-priority/ru/manage/events) | Да | Да |
| Ответить на [отзывы](https://yandex.ru/support/business-priority/ru/reviews/reviews) и пожаловаться на них | Да | Да |
| Объединить компании в [сеть](https://yandex.ru/support/business-priority/ru/branches/several-branches) | Да | Да |
| Подключить [онлайн-запись и бронирование](https://yandex.ru/support/business-priority/ru/manage/booking) | Да | Нет |
| Просмотреть [статистику](https://yandex.ru/support/business-priority/ru/manage/general-statistics) | Да | Да |
| Внести [правки](https://yandex.ru/support/business-priority/ru/manage/changes) с Яндекс Карт | Да | Нет |
| Изменить [территорию оказания услуг](https://yandex.ru/support/business-priority/ru/manage/address#online-territory), на которой работает компания | Нет | Да |
| Переделать профиль в [офлайн-компанию](https://yandex.ru/support/business-priority/ru/online-company#convert-it-online) | Нет | Да |

Подробнее о работе с профилем онлайн-компании см. в разделе [Особенности онлайн-компаний](https://yandex.ru/support/business-priority/ru/online-company).
